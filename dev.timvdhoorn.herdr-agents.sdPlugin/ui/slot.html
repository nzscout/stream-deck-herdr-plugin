Remote needs key-based SSH (no password prompt): ssh -o BatchMode=yes <target> 'echo ok' must print "ok". See README › Remote herdr over SSH.

A press raises the terminal hosting herdr; Windows Terminal can own several windows, so name one here if the wrong window comes up. The tab is selected with Ctrl+Alt+<n>. Set HERDR_DECK_TERMINAL_APP to override the detected host app.
